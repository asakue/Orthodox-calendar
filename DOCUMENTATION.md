## 2. Алгоритм расчета православной Пасхалии (`OrthodoxCalendarCalculator`)

Дата Святой Пасхи является краеугольным камнем православного календаря, определяющим все переходящие праздники года:
- Вход Господень в Иерусалим (Пасха - 7 дней)
- Великий Четверг (Пасха - 3 дня)
- Великая Пятница (Пасха - 2 дня)
- Светлая Пасхальная седмица (Пасха .. Пасха + 6 дней)
- Радоница (Пасха + 9 дней)
- Вознесение Господне (Пасха + 39 дней)
- День Святой Троицы / Пятидесятница (Пасха + 49 дней)
- День Святого Духа (Пасха + 50 дней)
- Неделя Всех Святых (Пасха + 56 дней)
- Начало Петрова поста (Пасха + 57 дней)

### Математический метод (Александрийский канон):

```kotlin
fun calculatePascha(year: Int): LocalDate {
    val a = year % 4
    val b = year % 7
    val c = year % 19
    val d = (19 * c + 15) % 30
    val e = (2 * a + 4 * b - d + 34) % 7
    val month = (d + e + 114) / 31
    val day = ((d + e + 114) % 31) + 1

    // Юлианская дата Пасхи
    val julianDate = LocalDate.of(year, month, day)

    // Смещение григорианского календаря (+13 дней для XX–XXI веков)
    return julianDate.plusDays(13L)
}
```

## 3. Модели данных и локальная база Room

### Таблицы базы данных:
- **`favorites`**: Сохранение избранных праздников и молитв с типами `FEAST` и `PRAYER`.
- **`reading_bookmarks`**: Закладки для чтения богослужебных текстов.

### Классы моделей:
- `OrthodoxHoliday`: Полная структура праздника (id, название, подзаголовок, дата, тип `FeastType`, тропарь, кондак, глас, величание, молитва, евангельское и апостольское зачала, история и духовный смысл).
- `OrthodoxDayInfo`: Комплексный снимок дня (новые и старые стили, святые, статус поста, тропари дня).
- `PrayerItem`: Структура молитвы (церковнославянский текст с ударениями, перевод, наставление святых отцов).

## 4. Виджет рабочего стола (`OrthodoxCalendarAppWidgetProvider`)

Виджет использует `RemoteViews` и обновляется системным `AppWidgetManager`.

- **Макет**: `res/layout/widget_orthodox_calendar.xml`
- **Конфигурация**: `res/xml/widget_orthodox_calendar_info.xml`
- **Функционал**:
  1. Автоматический расчет сегодняшнего дня и ближайшего великого праздника.
  2. Отображение правила поста дня (рыба, сухоядение, скоромный день).
  3. Клик по виджету запускает `MainActivity` через защищенный `PendingIntent.FLAG_IMMUTABLE`.

## 5. Уведомления и фоновые напоминания

- **Классы**: `NotificationHelper`, `OrthodoxAlarmReceiver`.
- **Канал уведомлений**: `CHANNEL_ID = "orthodox_calendar_channel"`.
- **Планировщик**: `AlarmManager.setInexactRepeating` настраивается на утреннее время (по умолчанию 08:00) с автоматическим восстановлением после перезагрузки устройства (`RECEIVE_BOOT_COMPLETED`).
- **Разрешения**: Поддержка `Manifest.permission.POST_NOTIFICATIONS` на Android 13+ (API 33+) с обработкой Runtime Permissions в Compose.

## 6. Темы, доступность и адаптивный дизайн

- **Адаптивность экрана**:
  - `maxWidth < 600.dp` — классический мобильный интерфейс с `NavigationBar`.
  - `maxWidth >= 600.dp` — эргономичный планшетный/десктопный режим с боковым `NavigationRail`.
- **Масштабирование текста**:
  - Использование `CompositionLocalProvider(LocalReadingFontScale)` и компонента `ScalableText` позволяет динамически увеличивать размер текста молитв до 135% без перезапуска приложения.
- **Темы**:
  - `OrthodoxLightColorScheme` (византийский пурпур `#801424`, золото `#B8860B`, пергамент `#FDFBF7`).
  - `OrthodoxDarkColorScheme` (ночной режим, обсидиан `#141213`, приглушенное золото `#E6C364`).
  - `OrthodoxParchmentColorScheme` (винтажный сепия-фон `#F4EBD9`).
